# Codebase Audit — 2026-09-24

## Scope and baseline

Repository: stephen-taipei/awesome-free-games-1000. Original main: `630cf47bca4047b26d0f8ddacdbc5273f9f85d41`.

Inventory: 997 game HTML pages, 6 source categories, 3,856 TypeScript files and 1,525 historical adjacent JavaScript files. Counts refer to repository files, not fully verified game designs. Static inventory, dependency analysis, full TypeScript checking and production build cover the repository; browser smoke tests explicitly have a narrower scope than full gameplay review.

The original `npm run build` passed but emitted only `dist/index.html`. Its sitemap advertised 998 URLs including all 997 game routes that the build did not publish. Baseline `tsc --noEmit` passed; there was no dedicated typecheck script or automated quality workflow. Baseline npm audit reported 5 affected development-tool packages: 4 high and 1 moderate. A source HTML reference scan found 126 missing local references (70 stylesheet, 20 icon, 17 manifest and 19 return links).

## Runtime repair detail

The first full Chromium run (`35936483888`) executed 1,004 tests: 970 passed, 34 failed, none skipped or retried. All 7 lobby tests passed. The 34 failing game pages were not excluded from the suite.

- 17 games attempted to draw fixed-size grids before Start initialized their board: puzzle 008, 009, 011, 023, 037, 041, 043, 077, 078, 087, 095, 126, 132, 136, 138 and action 287, 289. The initial resize now waits for a populated board; Start still initializes the model normally.
- 13 games (puzzle 064–076) published a GPU renderer before initialization completed and retained it after failure. The renderer is now private to initialization until success; existing non-GPU gameplay remains available when GPU support is absent.
- Word Search (030) cast a string translation result to an array, causing `.map` to throw. It now uses the actual typed locale word array with an English fallback.
- Shadow Chase (arcade 263) read an empty movement history during its idle preview. The proximity warning now waits for a recorded position.
- Oracle Warrior (action 355) passed a sine-derived negative radius to Canvas `arc`. The radius is now bounded at zero.
- Flip Puzzle (097) had a zero-height initial board area, allowing later controls to obstruct the Start button. Its layout now reserves overlay space without force-clicking the test.

Two literal `<` button labels in puzzle 079/098 were escaped to remove HTML parsing warnings. `scripts/migrations/fix-startup.mjs` records these exact, idempotent source repairs; normal CI is read-only and does not rewrite source files.

## Verification

Local verification after the runtime repairs passed **54 unit tests**, full TypeScript checking, and production construction with all **999 expected HTML pages**, no broken local HTML references and no HTML parse warnings. Unit coverage includes pre-start resize/draw behavior, optional GPU initialization in pending/failed/success states, typed word-list startup, and storage-failure regressions. Mocks do not certify real hardware rendering.

The baseline and dependency-resolution artifacts were generated by GitHub Actions. The final browser verdict is recorded on [PR #5](https://github.com/stephen-taipei/awesome-free-games-1000/pull/5) and the corresponding Quality run; use the actual run conclusion and JSON artifacts rather than inferring a pass from test definitions. Quality partitions the same full 1,004-test suite across four shards, with retries disabled and no excluded games.

```sh
npm ci
npm test
npm run typecheck
npm run build
npm audit --audit-level=high
npx playwright install --with-deps chromium
npm run test:e2e
```

Production validation expects homepage + static directory + all discovered games (999 HTML pages for this inventory). Tests fail on missing local references or uncompiled TypeScript entry tags. Browser tests use a strict static server beneath `/awesome-free-games-1000/`, not a dev-server SPA fallback; they exercise catalogue interactions, denied storage, static/no-JavaScript browsing, subpath navigation, mobile layout and each game page's short startup. Test results and screenshots are attached to the Quality workflow.

## Remaining limitations and follow-up

- No exhaustive manual playthrough of all 997 games, levels, scoring rules, end states, sound or touch interactions. A short Chromium boot/start smoke test cannot establish those properties.
- No claim of Safari/Firefox compatibility or successful real-device WebGPU rendering. Hardware/browser fallback and accessibility of each individual canvas game need focused review.
- Historical category/number inconsistencies and old adjacent generated JS remain: 225 numeric labels occur more than once (697 distinct labels across 997 paths). Path IDs prevent new catalogue/favorite collisions; existing per-game save-key collisions need a versioned migration before any renumbering.
- Per-game translation completeness varies; a 16-locale shared type is not proof of 16 complete translations. No Firebase backend, cloud leaderboard or offline PWA is configured.
- Repository has no LICENSE file. The maintainer must determine rights and choose license terms; this audit does not grant them.
- Passing repository checks does not establish that an external parent deployment or GitHub Pages site has updated. Deploy the generated dist artifact and verify the real hosting environment separately.
