# 疾風斬 Gale Cutter

WebGL（three.js）3D 浮空島衝刺斬擊動作遊戲。你是一名只會衝刺的風之忍者：按住讓時間慢到 15%，從腳下拉出一道發光的瞄準線；放開，就沿著那條線一閃而過，斬開線上的一切。

## 規則

- 你不能走路，只能衝刺。衝刺最長 5.4 公尺，遇到島緣、中央深淵或岩柱會在邊緣前停下，絕不會衝出島外；太短的瞄準（或拖到島外）會取消，不消耗衝刺。
- 衝刺有 3 格，約每 1.6 秒回充 1 格；只要這一刀斬倒任何敵人，立刻退還 1 格。沒有衝刺時放開會失敗，不會動。
- 慢動作靠「專注」維持（衝刺格下方的淡黃條），按住瞄準時以真實時間消耗（滿條約 2.5 秒），放開後回充，每斬倒一個敵人也會補一些。專注見底時仍可瞄準，只是時間恢復正常速度；第一次見底時會有提示與音效說明。
- 敵人：
  - 步兵：靠近後蓄力，地上的前撲路線先是橘色，變紅就鎖定方向，接著直線前撲。往旁邊衝開就能閃過。前撲被島緣擋住時身體停在邊緣，但攻擊仍會多伸出一小段（不會跨過深淵），所以躲在島緣凹角也不安全；步兵與盾兵在射程內卻沒有直線時會先繞位，最多 2.5 秒後照樣出手。
  - 弓手（第 3 波起）：保持距離拉弓，瞄準線變紅後放箭。飛行中的箭可以斬落（+30 × 倍率）。
  - 炸彈兵（第 5 波起）：靠近後點燃引信，地上出現紅色爆炸範圍。被你斬開時會立刻爆炸，波及範圍內的敵人並連鎖引爆其他炸彈兵，這種爆炸不會傷到你；讓引信自己燒完就會炸到你。
  - 盾兵（第 7 波起）：正面 120° 內的斬擊會被盾擋下（衝刺停在盾前、盾兵踉蹌 0.6 秒並中斷正在蓄力的盾擊），從側面或背後才斬得開。地上的淡藍扇形就是盾的方向。
- 被擊中扣 1 顆心（共 3 顆），之後有 1.2 秒無敵；衝刺過程也有極短的無敵。心全部失去就結束。
- 計分：步兵 100、弓手 150、盾兵 200、炸彈兵 80，乘上倍率。一刀斬倒 N 個敵人，倍率 +（N − 1），最高 ×30；一段時間沒有斬倒任何敵人倍率 −1（×5 以下 5 秒，之後每高一級少 0.15 秒，最短 2.5 秒），被擊中則歸回 ×1。清除一波得 250 × 波數（無傷加倍）；戰役每波回復 1 顆心，無盡模式每兩波回復 1 顆。
- 三座浮空島（迎風草原、琥珀梯田、風暴之冠），每座 4 波，共 12 波；之後是無盡模式，在三座島之間輪替，約二十波內持續變長、敵人更多（同場最多 12 名）、移動與盾的轉身更快。最佳分數與最佳倍率存在本機。

## 操作

| 滑鼠 / 鍵盤 | 觸控 | 動作 |
| --- | --- | --- |
| 按住左鍵，移動滑鼠 | 在畫面任意處拖曳 | 時間放慢並瞄準（觸控以拖曳方向與長度從忍者拉線：線的方向跟著手指，長度只看手指移動的距離，約短邊的四分之一就是最長衝刺） |
| 放開左鍵 | 放開手指 | 衝刺，斬開線上的一切 |
| 按住左鍵時按右鍵 | 幾乎沒拖動就放開 | 取消瞄準（之後放開左鍵不會衝刺） |
| 按住空白鍵（自動先對準最划算、而且衝得出去的敵人；沒有就選最長的有效衝刺），方向鍵 / WASD 移動準星，放開空白鍵 | | 鍵盤瞄準與衝刺 |
| P / Esc | 右上 ❚❚ | 暫停 |

分頁切到背景、遊戲失去焦點或打開語言選單時自動暫停；暫停時錯過的新敵人說明會在繼續後補上。倒下的動畫中不能暫停，結束畫面直接出現；此時還按著的按鍵不會立刻重新開始。

手機上整座島放不下時（直向約每單位 27 像素），鏡頭會拉近最多 1.5 倍並跟著忍者移動（瞄準時稍微往瞄準方向帶），但不會超出島的範圍；畫面外的敵人在邊緣有箭頭標示，正在蓄力或點燃引信的會變紅。

## 技術筆記

- `logic.ts`：純規則（無 DOM / three）。平頂六角格浮島、精確的可站立判定（到缺格多邊形的距離）、衝刺沿線行進加二分搜尋裁切到島緣、線段對圓的斬擊判定（起點後方與終點之後的不算）、盾的正面判定、炸彈爆炸的廣度優先連鎖、慢動作時間倍率、專注、命中停頓、倍率、出怪計畫與島間飛行。事件以陣列回傳給畫面層。
- `tests/game-324-wind-ninja.test.mjs`：證明公平性與邊界情況，包括每座島隨機 1500 次衝刺都不會離開地面、不能跳過深淵、盾的正背面規則、被盾擋下時盾後的敵人不受傷且盾擊被中斷、炸彈連鎖深度、衝刺與專注永不卡死、專注見底只通知一次、每種攻擊的預警時間下限、波次威脅在同一座島內不遞減、三座島上每一個可站的點（約 2000 處，含島緣凹角）站著不動都會被步兵與盾兵打到、攻擊的延伸絕不跨過虛空、鍵盤自動瞄準在有有效衝刺時絕不選到會被取消的方向、無盡模式持續升級與隔波回血、高倍率時限縮短，以及一個無敵的粗心機器人在 6 組亂數下都能清掉第 1 到 16 波（每座島都可清除），另一個不閃躲的機器人能撐過第一座島。
- `game.ts`：three.js 場景，透過共用 kit 建立。島嶼由擠出的六角磚、土層與倒錐岩根組成（InstancedMesh），草是加上 `onBeforeCompile` 擺動的實例化草葉，會被風、忍者和每次衝刺的尾流壓彎；岩柱上長著低多邊形樹。敵人是各自合併成單一頂點色幾何的膠囊 / 圓錐造型，每種一個 InstancedMesh。地面預警（蓄力圈、前撲路線、弓手視線、爆炸範圍、盾扇形、瞄準線、落點、斬擊標記、刀光）全部畫在同一個實例化四邊形上，由片段著色器依樣式繪製。衝刺留下十字交叉的光帶與殘影，粒子池負責火花。慢動作時霧拉近並染上冷色，鏡頭微微靠近。鏡頭以二分搜尋算出能把整座島框進 HUD 以外區域的距離，並用 `setViewOffset` 置中；寬螢幕選單時島會移到面板右側。這個距離下每單位不到 38 像素時（手機），改用跟隨鏡頭：依視野算出地面可見範圍，把目標夾在島的邊界內。忍者有淡色描邊、頭上一個畫在最上層的小箭頭，被敵人或岩柱擋住時會透出青色輪廓（一個包住忍者的凸膠囊，以 `GreaterDepth` 繪製並往鏡頭拉近 0.35，草不會誤觸發）；身邊同時有很多預警時，填色會變淡，外框與鎖定的紅線不變。觸控瞄準以忍者所在位置的螢幕到地面映射換算方向，長度只看手指移動的像素。全場約 15 到 25 次繪製呼叫。
- `main.ts`：DOM、HUD、覆蓋層（選單 / 遊戲中 / 暫停 / 結束）、提示與浮動分數、四種語言、最佳紀錄、量測 HUD 與網站導覽列並回報給鏡頭的安全區，以及 WebGL 不可用時的降級訊息。所有音效（慢動作、衝刺、斬擊、擋格、爆炸、風聲）都用共用 `Sfx` 合成。
- 系統要求減少動態效果時：不晃鏡頭、沒有命中停頓與衝刺推鏡、爆炸閃光減弱、引信不閃爍，受傷只有一次淡出的紅色邊框。
