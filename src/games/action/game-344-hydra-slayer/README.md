# 斬獸試煉 Beastfall Trials

WebGL（three.js）2.5D 首領對決。黃昏的懸崖頂端只有一片決鬥場，一次只面對一頭神話巨獸。側面透視鏡頭會依畫面大小與 HUD、觸控按鈕的位置重新取景，直式、橫式手機或中途旋轉都看得到完整的戰場。

## 規則

- 巨獸每一招出手前都有「起手」：發光、擺出架勢並發出聲音提示，然後才進入判定。
  - **金光**招式可以格擋。在命中前一瞬間按下格擋就是「完美格擋」：不受傷、巨獸踉蹌、專注 +25。太早或太晚只算普通格擋，會扣少量血量與體力，並把你推後一步。
  - 格擋揮空後 0.5 秒內再按一次是「倉促格擋」：沒有完美判定、收招也更久，所以連打格擋鍵不會變成完美格擋。
  - **赤光**招式無法格擋，只能翻滾穿過（翻滾有無敵時間），或在地面標示亮起時走出範圍。
  - 海妖的**青色音符**也能格擋。
  - 選單上的圖例會先教這三種顏色；每種顏色第一次出現時，畫面中央也會提示一次（開場提示不會把它蓋掉）。
- 攻擊是三段連擊。巨獸在防禦中時只吃 35% 傷害，還會被激怒提早出手；在牠出招後的硬直或踉蹌時下手，才能打出全額傷害。
- 翻滾消耗體力，體力停用 0.5 秒後才開始回復。
- 專注集滿後可以施放終結技：全程無敵、無視防禦、傷害 60。揮空會退還專注。
- 試煉依序是三首獄犬 → 海妖 → 九頭蛇 → 深淵巨妖，一頭比一頭難（測試會證明這個順序）。每頭巨獸都只有一個核心考驗：
  - **三首獄犬**：三顆頭各自從頸部伸出、輪流撲咬，節奏一拍接一拍，咬的那顆頭會單獨前衝發光；只要其中一口完美格擋，整串咬完後牠就會踉蹌。蓄力撲擊是赤光。
  - **海妖**：歌聲會把你拖向崖邊，掉下去會受傷並在後方重生。格擋任何一個音符就能打斷歌聲；完美格擋會讓她跌落到崖邊，成為攻擊的好時機。
  - **九頭蛇**：只有低頭咬下或橫掃時，頭才打得到。砍斷的頭會再長回來；長回來之前，斷頸是可以砍的目標，每一刀都會累積專注，正好用來施放終結技把它徹底燒掉。三顆頭都燒掉才算勝利。頭全斷時，斷頸會噴出赤光毒液，不會讓你空等。
  - **深淵巨妖**：觸手會從地面發光處破土而出。標示先跟著你移動，出手前 0.5 秒鎖定（邊緣變亮），之後再走開就躲得掉；觸手與重擊會混合出招。巨妖浮出水面時頭部才打得到，你站得太近時牠會用喙啄擊，暴怒後連啄兩下。巨妖潛入水中時施放終結技，提示是「沒有目標」而不是「太遠」。
- 獄犬、海妖與巨妖在血量剩一半時暴怒；九頭蛇則是每長回一顆頭、每燒掉一顆頭就更兇猛。暴怒後出手更快、休息更短，但任何招式的起手都不會短於 0.3 秒。
- 試煉表：擊敗一頭才會解鎖下一頭；四頭都在普通難度擊敗後，開放更快、更痛的「夢魘」難度。每頭巨獸、每個難度各自記錄最快時間；整場不被打中（格擋不算被打中）可獲得無傷勳章 ★。

## 操作

| 輸入 | 動作 |
| --- | --- |
| A D / ← →、拖曳畫面左半邊 | 左右移動 |
| J / Space、⚔ 攻擊鍵 | 三段連擊 |
| K / Shift、盾牌鍵 | 格擋（金光、青色音符） |
| L / ↓ / S、翻滾鍵 | 翻滾閃避（往按住的方向，預設向後） |
| I / ↑ / W、★ 鍵 | 專注終結技（集滿時發光） |
| P / Esc、暫停鍵 | 暫停；切到其他分頁或視窗也會自動暫停 |

## 技術

- `logic.ts`：純規則，不依賴 three.js 或 DOM。以固定 1/120 秒步進的 `Duel` 處理英雄的連擊、格擋、翻滾無敵與終結技；每頭巨獸是一個狀態機，產生帶有起手／判定／收招時間與命中範圍的 `Strike`。所有招式的幀數表（`ATTACKS`）、難度（`TIERS`）、試煉表與紀錄編碼都在這裡。
- `tests/game-344-hydra-slayer.test.mjs`：證明公平性與難度曲線。夢魘難度加暴怒時每招起手仍 ≥ 300 ms；格擋判定與翻滾無敵時間能涵蓋每一招的判定時間；每一招金光都能完美格擋、每一招都能原地翻滾躲過；連續招式的判定間隔不低於下限；只用畫面資訊的腳本機器人（格擋＋翻滾）能在兩種難度擊敗四頭巨獸，什麼都不做則必敗；帶有反應時間與時機誤差的「類人」機器人能穩定通過普通難度，而且剩餘血量依試煉順序遞減、夢魘一定比普通難；連打格擋鍵每場最多拿到約一次完美格擋；九頭蛇沒有終結技就贏不了、砍斷頸會累積專注、頭全斷時也不會讓英雄閒著；巨妖觸手先追蹤再鎖定、潛水時終結技回報「沒有目標」；另外涵蓋崖邊墜落、歌聲中斷、試煉表解鎖與時間紀錄編碼等邊界情況。
- `game.ts`：three.js 場景與遊戲迴圈。鏡頭把英雄與巨獸的範圍放進 HUD 與觸控按鈕之外的安全區域（`setInsets`），視窗縮放或旋轉時立即重新取景；決鬥場本身的尺寸固定，與畫面無關。命中停頓、慢動作、鏡頭震動與擊退在系統要求減少動態效果時全部關閉，閃光也會減弱；受擊閃光不論設定都以真實時間限速，每個目標每秒少於 3 次。
- `art.ts`、`hero.ts`、`beasts.ts`：全部以基本幾何體程序生成。脖子、觸手、尾巴與頭髮是沿 CatmullRom 曲線即時重建的 TubeGeometry；姿勢由程式補間；材質加上菲涅耳邊緣光與受擊閃光；火花是一個共用的點雲；地面警示是 shader 平面。劍光拖尾在每次揮劍開始時重設，不會拉出殘影楔形；每幀的向量與顏色都預先配置，不在迴圈中產生垃圾。整個場景約 60–80 次 draw call。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、鍵盤與指標輸入、合成音效、最佳紀錄、i18n）。沒有 WebGL 時，選單面板以說明取代開始鍵。
