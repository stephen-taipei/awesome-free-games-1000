# 後室逃生 Backrooms Escape

WebGL（three.js）第一人稱恐怖探索。你掉進「後室」：無盡的單調黃色辦公室、潮濕的地毯、嗡嗡作響的日光燈。每一層都要在迷宮裡找到 3 瓶杏仁水，出口的門才會解鎖；走出去之後，下一層更大，也更暗。

## 規則

- 找到 3 瓶杏仁水（HUD 顯示 x/3），出口上方的 EXIT 燈號會由紅轉綠，走到門前即可進入下一層。
- 迷宮裡有一個高瘦的黑影在遊蕩。它會巡邏，聽得見你衝刺的腳步聲，看見你就會追上來；被抓到就結束。
- 手電筒讓你看得更遠，但也讓它從更遠的地方看見你。電量有限，可撿拾電池補充。
- 衝刺會消耗體力，耗盡後要喘一會兒才能再衝。
- 它靠近時，附近的燈管會閃爍，日光燈的嗡嗡聲會變調，心跳聲越來越快。
- 沒有地圖。按 E 可在牆上畫粉筆記號（面前沒有牆時在地上畫箭頭），幫自己記路。
- 計分：每瓶杏仁水 100、每顆電池 25、通過第 N 層 500 × N。最佳分數存在本機。

## 操作

| 鍵盤 / 滑鼠 | 觸控 | 動作 |
| --- | --- | --- |
| W A S D / ↑ ↓ | 左半邊拖曳（虛擬搖桿） | 移動 |
| 滑鼠（點擊畫面鎖定）/ ← → | 右半邊拖曳 | 環顧 |
| Shift | 右側 » 按鈕（按住） | 衝刺 |
| F | 右側手電筒按鈕 | 手電筒開關 |
| E | 右側 ✕ 按鈕 | 粉筆記號 |
| P / Esc | 右上 ❚❚ | 暫停 |

不鎖定滑鼠也能玩：可拖曳畫面或用 ← → 轉向。分頁切到背景時自動暫停。

## 技術筆記

- `logic.ts`：純規則（無 DOM / three），包含以種子亂數產生的迷宮（遞迴回溯 + 打通部分牆形成迴圈 + 有柱子的大廳）、格子圓形碰撞、格子射線視線判定、體力、黑影的感知（視覺 / 聽覺）與追蹤狀態機。測試在 `tests/game-589-backrooms-escape.test.mjs`。
- `game.ts`：three.js 場景。牆面合併成單一 BufferGeometry（只產生面向走道的面），天花板燈管與光暈用 InstancedMesh，壁紙、地毯、天花板、燈管、粉筆、EXIT 燈號都是 CanvasTexture 程序貼圖。只有 5 盞真實 PointLight，跟著玩家附近最近的亮燈管移動並淡入淡出（light pooling），再加上手電筒 SpotLight 與霧。黑影用頂點擾動著色器與半透明外殼，讓輪廓永遠看不清。
- `hum.ts`：日光燈嗡嗡聲（持續音，暫停時淡出並暫停 AudioContext），隨黑影接近加入失真與顫音；其他音效使用共用 `Sfx`。
- `main.ts`：DOM、HUD、覆蓋層（選單 / 遊戲中 / 暫停 / 結束）、Pointer Lock、觸控按鈕、最佳分數與 WebGL 不可用時的降級訊息。
