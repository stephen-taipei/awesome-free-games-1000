# 燈塔守夜 Lighthouse Watch

WebGL（three.js）3D 暴風雨恐怖守塔遊戲。你是孤岩燈塔的守燈人，暴風雨夜裡，蒼白的溺魂從黑海中浮起，從四面八方涉水、爬上礁岩，朝塔門而來。你唯一的武器就是燈塔的光束。

## 規則

- 寬光束（平時）只能拖慢照到的亡魂；按住聚焦後光束變窄變強，照住亡魂一小段時間就能把它燒散。移開光束後，燒灼會慢慢退去。
- 聚焦會消耗燈油，不聚焦時燈芯會慢慢回油；燈油見底就無法聚焦，要回到一定油量才能再點燃。
- 海上會漂來油桶與木箱。用聚焦光束照住一會兒就能拉回來：油桶 +40 燈油，木箱 +20 燈油並重新點亮一盞燈籠（燈籠全亮時改為 +50 分）。沒人理會的漂流物會沉沒；燈油越少，漂流物來得越勤。
- 亡魂碰到塔門會熄滅一盞燈籠（共 3 盞），同時爆出的閃光會把附近的亡魂震回海裡。三盞全滅，燈塔熄燈，遊戲結束。
- 每一夜的亡魂更多、更快、更耐燒，並陸續加入新種類：
  - 溺魂：基本型，第 1 夜。
  - 爬行者：又快又會蛇行，第 2 夜。
  - 巨影：體型大，要燒很久，第 3 夜。
  - 注視者：只在沒被光照到時移動，一旦沒看著它就會衝過來；閃電照亮海面時也會定住。第 4 夜起出現。
- 計分：驅散溺魂 10、爬行者 15、注視者 25、巨影 35，每過一夜加成 15%；撐過第 N 夜再加 50 × N。最佳分數存在本機。

## 操作

| 鍵盤 / 滑鼠 | 觸控 | 動作 |
| --- | --- | --- |
| ← → / A D | ◀ ▶ 按鈕 | 旋轉光束 |
| 空白鍵 / ↑ / W（按住） | ◉ 按鈕（按住） | 聚焦光束 |
| 滑鼠指向 | 按住畫面 | 光束轉向該處（觸控在光束轉到後聚焦） |
| 按住滑鼠左鍵 | | 聚焦光束 |
| P / Esc | 右上 ❚❚ | 暫停 |

分頁切到背景或遊戲失去焦點（例如點擊嵌入頁面的其他地方）時自動暫停。

## 技術筆記

- `logic.ts`：純規則（無 DOM / three）。以極座標（角度、距離）模擬亡魂、漂流物、燈油、燈籠與每夜的出怪計畫，事件以陣列回傳給畫面層。測試在 `tests/game-608-lighthouse-horror.test.mjs`。
- `game.ts`：three.js 場景，透過共用 kit 建立。海面用 `onBeforeCompile` 在頂點著色器疊加多組正弦波並計算法線；海面、礁岩、雨滴共用同一組光束 uniform，所以光束照到哪裡就亮到哪裡。光束本體是加成混合的「光柱帳篷」ShaderMaterial，另加一盞 SpotLight。指數霧、閃電（閃光燈、霧與背景同步變化，加上閃電條帶）、雨滴 LineSegments、火花粒子池。亡魂是 LatheGeometry 長袍加自發光淡綠眼睛與光暈 sprite，依種類組裝並以物件池重用。畫面外的亡魂會在畫面邊緣顯示眼睛標記。
- `main.ts`：DOM、HUD、覆蓋層（選單 / 遊戲中 / 暫停 / 結束）、驚嚇閃光、觸控按鈕、四種語言、最佳分數，以及 WebGL 不可用時的降級訊息。所有音效（燒灼、驅散鐘聲、撞門、雷聲、浪聲）都用共用 `Sfx` 合成。
