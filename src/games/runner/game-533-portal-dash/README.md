# 傳送門衝刺 Portal Dash

WebGL（three.js）3D 霓虹隧道跑酷。鏡頭跟著你沿隧道壁旋轉，整條隧道會繞著你滾動。

## 規則

- 牆分成青、粉兩色。與你同色的牆是幻影，可以直接穿過；異色的牆是實體，撞到就結束。
- 穿過傳送門會自動換色，並進入下一個區段（速度提高、配色改變）。
- 手動換色要消耗 1 格「換相」。每收集 4 個晶片補 1 格，最多 3 格。
- 傳送門後若出現整圈的牆，它的顏色一定等於傳送門給你的顏色：不要亂換。
- 每一排障礙都保證有一個只靠移動就到得了的缺口，換色是捷徑，不是必要條件（整圈牆除外）。

## 操作

| 輸入 | 動作 |
| --- | --- |
| ← → / A D、左右拖曳 | 沿隧道壁移動 |
| Space / ↑ / W、點一下 | 手動換色 |
| P / Esc | 暫停 |

## 技術

- `logic.ts`：純規則（軌道產生、角度碰撞、相位），由 `tests/game-533-portal-dash.test.mjs` 驗證每排都有可達缺口。
- `game.ts`：three.js 場景。隧道是 BackSide 圓柱加自訂 shader 網格；障礙是擠出的環扇形與邊線；晶片、傳送門、速度粒子與撞毀粒子。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、輸入、音效、最佳紀錄、i18n）。沒有 WebGL 時顯示說明並停用開始鍵。
