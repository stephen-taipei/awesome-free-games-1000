# 天際線大逃亡 Skyline Getaway

WebGL（three.js）2.5D 屋頂追逐跑酷。鏡頭固定在側面，警用無人機帶著探照燈從後方追來，你在程序產生的天際線上自動奔跑。

## 規則

- 速度就是生命條。無人機有自己的速度（速度條上的紅色刻度）；你比它慢，光圈就會逼近，「領先」距離歸零就被照住。
- 時機抓準的動作是「完美動作」，會加速並累積連段：翻越冷氣機、滑過管線下方、蹬牆攀上高樓、重落地前翻滾卸力、在邊緣起跳、抓住滑索。連段越長，每次加速越多。
- 時機不對會踉蹌減速、連段歸零；沒跳過建築之間的缺口就會墜落，跑局結束。
- 下一個要處理的障礙上方會出現圓環提示，圓環填滿變綠時就是完美時機。判定時間會從 180 ms 隨距離縮到 110 ms。
- 每 500 m 進入新街區：黃昏屋頂、霓虹雨巷、港口吊臂、遊樂園、車站天棚，之後循環。每個街區提高最高速度（8 → 16 m/s），加入新的場景機關（蹬牆高樓、吊臂跳台、滑索、會塌陷的玻璃天棚），缺口變寬、機關變密，無人機也變快。
- 跳躍有郊狼時間（離開邊緣後 0.1 秒內仍可起跳）與輸入緩衝（落地前 0.13 秒內按下也算）。
- 最佳距離存在本機（`afg-skyline-getaway-best`）。

## 操作

| 輸入 | 動作 |
| --- | --- |
| Space / W / ↑、點一下 | 小跳；翻越、蹬牆、抓滑索 |
| 按住 Space / W / ↑、按住畫面 | 跳遠（放開就開始下落） |
| S / ↓、向下滑 | 滑過管線下方；重落地前按下就翻滾 |
| P / Esc | 暫停 |

## 技術

- `logic.ts`：純規則，沒有 DOM 與 three.js。固定步長模擬（1/120 秒）、跳躍物理、判定窗、郊狼時間與緩衝、腳本化的翻越／攀爬／蹬牆動作、天棚塌陷、滑索，以及路線產生器。缺口寬度由 `maxGap(地板速度, 高低差)` 限制，所以就算一直被減速到街區的地板速度，每個缺口按住跳躍都跳得過去；屋頂高度會往 0 回拉，讓需要空間的機關持續出現。
- `tests/game-383-parkour-master.test.mjs`：驗證每個缺口在地板速度與最高速度之間都跳得過（40 組種子、超過 2000 個缺口）、動量經濟（判定窗 180 → 110 ms、踉蹌懲罰、完美加速）、追兵距離等於「速度減無人機速度」的積分、各種動作與失誤的判定，以及完美機器人跑完所有街區不踉蹌、隨便亂按的機器人會先收到警告再被抓。
- `art.ts`：五個街區的配色與漸變、窗格大樓 ShaderMaterial（窗戶、屋頂磚、貨櫃、蹬牆看板、霓虹招牌、探照燈光斑）、天空與遠景剪影 shader、探照燈光錐、以頂點色合併的道具幾何（冷氣機、管線架、吊臂、滑索桅杆、摩天輪、無人機）與跑者骨架。
- `game.ts`：three.js 場景。大樓、道具與背景都用 InstancedMesh，一般每格約 35 次繪製呼叫；兩層視差背景、雨絲、塵土與火花粒子、速度線、計時圓環。系統要求減少動態效果時，不晃鏡頭、不做 FOV 衝刺，無人機警燈改為恆亮；所有閃爍都低於 3 Hz。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、輸入、音效、最佳紀錄、i18n）。所有美術與音效都在程式裡產生。沒有 WebGL 時，選單面板以說明取代開始鍵。
