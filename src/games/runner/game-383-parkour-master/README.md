# 天際線大逃亡 Skyline Getaway

WebGL（three.js）2.5D 屋頂追逐跑酷。鏡頭固定在側面，警用無人機帶著探照燈從後方追來，你在程序產生的天際線上自動奔跑。

## 規則

- 速度就是生命條。無人機有自己的速度（速度條上的紅色刻度）；你比它慢，光圈就會逼近，「領先」距離歸零就被照住。
- 時機抓準的動作是「完美動作」，會加速並累積連段：翻越冷氣機、滑過管線下方、蹬牆攀上高樓、重落地前翻滾卸力、在邊緣起跳、抓住滑索。連段越長，每次加速越多。
- 時機不對會踉蹌減速、連段歸零；沒跳過建築之間的缺口就會墜落，跑局結束。結算畫面會說明墜落的原因：直接跑出邊緣、跳得不夠遠，或跳過了頭。
- 按住跳躍一路到落地永遠不會害你墜落：吊臂、天棚與缺口後的屋頂都至少有「最高速度、郊狼時間最後一刻起跳、全程按住」那一跳的長度，還留有對準下一跳的距離。
- 下一個要處理的障礙上方會出現圓環提示，圓環填滿變綠時就是完美時機。判定時間會從 180 ms 隨距離縮到 110 ms。
- 每 500 m 進入新街區：黃昏屋頂、霓虹雨巷、港口吊臂、遊樂園、車站天棚，之後循環。每個街區提高最高速度（8 → 16 m/s），加入新的場景機關（蹬牆高樓、吊臂跳台、滑索、會塌陷的玻璃天棚），缺口變寬、機關變密，無人機也變快。每個街區保證出現自己的招牌機關：第一輪至少 3 次，之後每輪至少 2 次。
- 跳躍有郊狼時間（離開邊緣後 0.1 秒內仍可起跳，邊緣的圓環提示也會留到這段時間結束）與輸入緩衝（落地前 0.13 秒內按下也算）。跳向較高的屋頂時，若撞上牆面時還在快速上升、本來就跳得過，會順勢踩牆翻上去。
- 暫停（含切換視窗自動暫停）後繼續時，會先以慢動作在 0.9 秒內回到正常速度。
- 最佳距離存在本機（`afg-skyline-getaway-best`）。

## 操作

| 輸入 | 動作 |
| --- | --- |
| Space / W / ↑、點一下 | 小跳；翻越、蹬牆、抓滑索 |
| 按住 Space / W / ↑、按住畫面 | 跳遠（放開就開始下落） |
| S / ↓、向下滑 | 滑過管線下方；重落地前按下就翻滾 |
| P / Esc | 暫停 |

觸控細節：向下滑的時機從手指按下（或開始往下移動）的那一刻起算，不是從系統認出滑動的時候，而且用的是觸控事件本身記下的時間，所以畫面忙碌、事件晚到時也不會算錯；如果這次觸碰已經先讓跑者小跳，滑動會把那一跳收回、直接在屋頂上滑鏟（在缺口邊緣則不收回，照樣跳過去）。還沒判斷出是點按或滑動的短暫期間，跳進管線的碰撞與重落地後的跳躍都會先等一下。每一根手指都能點跳，放在畫面上的拇指不會擋住其他手指；按住跳遠由最後按下的那根手指決定。鍵盤不受這些影響：跳起後按 S 只會在落地時滑鏟或翻滾，不會把你往下拉。

## 技術

- `logic.ts`：純規則，沒有 DOM 與 three.js。固定步長模擬（1/120 秒）、跳躍物理、判定窗、郊狼時間與緩衝、腳本化的翻越／攀爬／蹬牆動作、天棚塌陷、滑索，以及路線產生器。缺口寬度由 `maxGap(地板速度, 高低差)` 限制，所以就算一直被減速到街區的地板速度，每個缺口按住跳躍都跳得過去；缺口之後的落點長度至少是 `longestJump(最高速度, 高低差)` 加上預留距離，所以全程按住也不會跳過頭。屋頂高度會往 0 回拉；招牌機關因高度放不下時，先產生一段往合適高度走的屋頂再補上。觸控輸入帶有滑動的起算時間（`swipeAge`）、是否與上一次跳躍同一次觸碰（`sameTouch`），以及「可能還會變成滑動」（`undecided`）。
- `tests/game-383-parkour-master.test.mjs`：驗證每個缺口在地板速度與最高速度之間都跳得過（40 組種子、超過 2000 個缺口）；全程按住跳躍在任何速度、從判定窗最早到郊狼時間最後一刻起跳都不會墜落（超過 3000 跳，其中上百次跳上吊臂）；動量經濟（判定窗 180 → 110 ms、踉蹌懲罰、完美加速）、追兵距離等於「速度減無人機速度」的積分、各種動作與失誤的判定、墜落原因、觸控滑動的起算與收回小跳、鍵盤跳起後按 S 不會被拉下、每個街區的招牌機關數量與機關密度隨距離上升，以及完美機器人跑完所有街區不踉蹌、隨便亂按的機器人會先收到警告再被抓。
- `art.ts`：五個街區的配色與漸變、窗格大樓 ShaderMaterial（窗戶、屋頂磚、貨櫃、蹬牆看板、霓虹招牌、探照燈光斑）、天空與遠景剪影 shader、探照燈光錐、以頂點色合併的道具幾何（冷氣機、管線架、吊臂、滑索桅杆、摩天輪、無人機）與跑者骨架。
- `game.ts`：three.js 場景。大樓、道具與背景都用 InstancedMesh，一般每格約 35 次繪製呼叫；兩層視差背景、雨絲、塵土與火花粒子、速度線、計時圓環。鏡頭在空中會對準預測的落點，地面上會略為看向前方較低的屋頂；橫放手機時依高度保留足夠視野，直式畫面把屋頂線放在約三分之二高處。計時圓環一定保持在畫面內（HUD 下方、底邊上方）。系統要求減少動態效果時，不晃鏡頭、不做 FOV 衝刺，無人機警燈改為恆亮；所有閃爍都低於 3 Hz。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、輸入、音效、最佳紀錄、i18n）。所有美術與音效都在程式裡產生。沒有 WebGL 時，選單面板以說明取代開始鍵。
