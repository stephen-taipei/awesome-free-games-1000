# 山脊滑翔 Ridge Glider

WebGL（three.js）3D 翼裝飛行。鏡頭跟在身後，沿著程序生成的山脊峽谷一路滑翔向下，靠能量管理活下去：升力和速度的平方成正比。

## 規則

- 俯衝把高度換成速度，拉起把速度換回高度。拉起會耗掉一些能量，所以沒有熱氣流或推進時，總能量只會減少。
- 放開搖桿時翼裝維持約 4.5 : 1 的快速滑翔，比谷底下降得快，所以放手不管一定會越飛越低；稍微拉一點、放慢到約 100 km/h 才是最省高度的滑翔（約 5.5 : 1）。
- 速度低於失速速度就會失速：升力不到 1 g、阻力變大、機頭一路往下掉，直到俯衝把速度拿回來為止。一直拉到底只會一再失速、白白掉高度。
- 光環沿著一條「理想航線」排列，有的在低谷、有的在高處。連續穿過光環累積連環，每 3 環倍率加 1（最高 ×5）；錯過一環連環歸零。
- 每飛 1 公尺得「倍率」分；離地 9 公尺內、時速 100 公里以上貼地飛行時加倍。每穿過一環另得 50 × 倍率。最佳分數存在瀏覽器裡。
- 推進共 3 格，每格加速約 1 秒；連穿 4 環補 1 格。
- 發光的熱氣流柱立在光環航線上，核心很窄：從正中間穿過推力最大，擦到邊緣幾乎沒有。放慢速度穿過能待得更久、爬得更高。這是越飛越低時重新爬升的主要方法。
- 每過一段難度提高：峽谷變窄、地勢變平緩、光環變小變密；第 2 段起出現必須從鞍部穿過的山脊，第 3 段起有側風。第 10 段起每段繼續收緊：陣風更急、光環更小、山脊更高更寬、鞍部更窄、熱氣流更稀，到第 15 段達到最高難度並維持下去（測試證明這個難度仍飛得過）。地面顏色每三段換一次（草原、秋林、高山、暮色花崗岩），天色也一路走向黃昏。
- 「拉起！」警告：假設你再維持目前的操作約 0.45 秒（反應時間）才全力拉起，若仍會離地不到 6 公尺就亮起，並至少持續 0.6 秒、不會閃爍。看到後立刻拉起就來得及；貼地平飛不會觸發。
- 前 20 秒有安全氣流：碰到地面會被彈回空中（連環歸零）。之後撞到谷底、岩壁或山脊就結束，結算畫面會依撞到的地形說明原因。

## 操作

| 輸入 | 動作 |
| --- | --- |
| ↑ / W | 拉起爬升 |
| ↓ / S | 俯衝加速 |
| ← → / A D | 左右傾斜轉向（放開自動改平） |
| Space | 推進 |
| P / Esc | 暫停 |
| 觸控：任意處拖曳 | 虛擬搖桿：往上爬升、往下俯衝、左右轉向，放開自動改平 |
| 觸控：第二指快速點一下 / ⇧ 鈕 | 推進（按住不放的手指或手掌不會觸發） |

選單可勾選「反轉俯仰」，改成飛行模擬器的操作（往上推是俯衝）；鍵盤、觸控搖桿與畫面提示都會一起反轉。

## 技術

- `logic.ts`：純規則。點質量飛行模型（航跡角、航向、坡度；升力 ∝ V²，誘導阻力與拉起耗能，失速低頭），種子化的航線、地形高度（與 `PlaneGeometry` 網格逐三角形一致的 `surfaceHeight`）、山脊鞍部、熱氣流、側風、光環與計分，以及測試用的自動駕駛。
- `tests/game-421-wingsuit-run.test.mjs`：驗證俯衝後拉起能爬回大部分高度、無外力時能量不會增加、最高速仍能沿航線穿過每個光環、航線與光環在所有地形上都有離地餘裕、山脊都有鞍部，以及自動駕駛能飛完 16 公里（超過最高難度的第 15 段）不撞地（證明沒有躲不掉的地形）。也驗證平衡與提示：放手不管約一分鐘內就會落地、一直拉到底更快；只會追光環、看到警告才拉起的「笨拙玩家」在每條航線上都活得更久、分數更高；「拉起！」至少提早 0.8 秒出現，看到後 0.3 秒再拉起能救回 90% 以上的俯衝；警告不閃爍、不干擾貼地飛行；連環中斷只回報 miss，不會觸發倍率音效。
- `game.ts`：three.js 場景。地形是 7 塊環狀重複使用的區塊：以 `PlaneGeometry` 的格點與三角形計算高度（與碰撞完全相同），再展開成每個面各自上色的低多邊形網格（岩、雪、草、林依坡度、高度與所在段落的地貌混色，加霧），光環與光暈、熱氣流柱、雲都用 InstancedMesh；腳上的煙帶（環狀緩衝區）、速度線、火花與塵土粒子；每幀重複使用暫存物件，不產生垃圾；繪製呼叫約 20 次。直式手機會自動放大垂直視角，讓峽谷不被裁成一條縫。墜毀時鏡頭退到側後方俯看墜落點。系統要求減少動態效果時，不晃鏡頭、不脈動、視野變化減弱，鏡頭幾乎不跟著側傾。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、輸入、音效、最佳紀錄、i18n）。kit 沒有可循環的噪音音源，風聲由每 50 毫秒一段、同時重疊六段的短噪音組成，起伏約 2 dB，濾波頻率跟著速度變。沒有 WebGL 時，選單面板以說明取代開始鍵。
