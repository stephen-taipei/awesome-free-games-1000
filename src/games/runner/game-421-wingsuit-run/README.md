# 山脊滑翔 Ridge Glider

WebGL（three.js）3D 翼裝飛行。鏡頭跟在身後，沿著程序生成的山脊峽谷一路滑翔向下，靠能量管理活下去：升力和速度的平方成正比。

## 規則

- 俯衝把高度換成速度，拉起把速度換回高度。拉起會耗掉一些能量，所以沒有熱氣流或推進時，總能量只會減少。速度低於失速速度時機頭會自己往下掉。
- 光環沿著一條「理想航線」排列，有的在低谷、有的在高處。連續穿過光環累積連環，每 3 環倍率加 1（最高 ×5）；錯過一環連環歸零。
- 每飛 1 公尺得「倍率」分，離地 9 公尺內貼地飛行時加倍；每穿過一環另得 50 × 倍率。最佳分數存在瀏覽器裡。
- 推進共 3 格，每格加速約 1 秒；連穿 4 環補 1 格。
- 發光的熱氣流柱會把你往上推，是越飛越低時重新爬升的主要方法。
- 每過一段難度提高：峽谷變窄、地勢變平緩、光環變小變密；第 2 段起出現必須從鞍部穿過的山脊，第 3 段起有側風。
- 前 20 秒有安全氣流：碰到地面會被彈回空中（連環歸零）。之後撞到谷底、岩壁或山脊就結束。

## 操作

| 輸入 | 動作 |
| --- | --- |
| ↑ / W | 拉起爬升 |
| ↓ / S | 俯衝加速 |
| ← → / A D | 左右傾斜轉向（放開自動改平） |
| Space | 推進 |
| P / Esc | 暫停 |
| 觸控：任意處拖曳 | 虛擬搖桿：往上爬升、往下俯衝、左右轉向，放開自動改平 |
| 觸控：第二指點一下 / ⇧ 鈕 | 推進 |

選單可勾選「反轉俯仰」，改成飛行模擬器的操作（往上推是俯衝）。

## 技術

- `logic.ts`：純規則。點質量飛行模型（航跡角、航向、坡度；升力 ∝ V²，誘導阻力與拉起耗能，失速低頭），種子化的航線、地形高度（與 `PlaneGeometry` 網格逐三角形一致的 `surfaceHeight`）、山脊鞍部、熱氣流、側風、光環與計分，以及測試用的自動駕駛。
- `tests/game-421-wingsuit-run.test.mjs`：驗證俯衝後拉起能爬回大部分高度、無外力時能量不會增加、最高速仍能沿航線穿過每個光環、航線與光環在所有地形上都有離地餘裕、山脊都有鞍部，以及自動駕駛能飛完 12 公里不撞地（證明沒有躲不掉的地形）。
- `game.ts`：three.js 場景。地形是 7 塊環狀重複使用的區塊：以 `PlaneGeometry` 的格點與三角形計算高度（與碰撞完全相同），再展開成每個面各自上色的低多邊形網格（岩、雪、草、林依坡度與高度混色，加霧），光環與光暈、熱氣流柱、雲都用 InstancedMesh；腳上的煙帶、速度線、火花與塵土粒子；繪製呼叫約 20 次。直式手機會自動放大垂直視角，讓峽谷不被裁成一條縫。墜毀時鏡頭退到側後方俯看墜落點。系統要求減少動態效果時，不晃鏡頭、不脈動、視野變化減弱。
- 共用 `src/shared/three/kit.ts`（舞台、迴圈、輸入、音效、最佳紀錄、i18n）。風聲由連續的短噪音片段組成，濾波頻率跟著速度變。沒有 WebGL 時，選單面板以說明取代開始鍵。
